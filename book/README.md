# Building Zero-Knowledge & Blind Credential Systems

## Constructing BlindPass from Scratch

The maintained manuscript follows the 13-chapter, code-first path in
[`chapters/`](chapters/). Build the expanded edition with every source listing
embedded in full:

```bash
pnpm book:build
```

The result is
[`building-zero-knowledge-blind-credentials.md`](building-zero-knowledge-blind-credentials.md).
CI and reviewers can detect stale listings with `pnpm book:check`.

The older numbered notes at this directory's top level predate this edition.
They remain as short supplementary reading, but the generated manuscript is the
authoritative book.
